# Flask Todo App Documentation

Welcome to the Flask Todo App documentation. This application is a modern task management system built with Flask, featuring OAuth authentication and Markdown support.

## Features

- User authentication (Local and OAuth)
- Task management with priorities
- Markdown support for task content
- Responsive design
- RESTful API

## Quick Start

# Clone the repository
`git clone https://github.com/yourusername/flask-todo-app`

# Install dependencies
`pip install -r requirements.txt`

# Set up environment variables
`cp .env.example .env`

# Run the application
`python run.py`
